# Hive Council

**Safety:** Do not commit API keys or personal information. This repository is currently public. The Council worker will be developed on a separate branch and will default to dry-run/mock mode. Existing Hive controllers remain unchanged.

Phase 0: Muse autonomous GitHub handshake completed (Issue #1). Phase 1: GPT/Gemini worker under development.
